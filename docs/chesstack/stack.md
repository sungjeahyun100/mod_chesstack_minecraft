# 기물 점수 (Piece Score)

이 문서는 체스택에서 사용되는 기물 점수 테이블을 정리합니다.
기물 점수는 포켓(덱) 구성 시 총합 제한(39점)의 기준이 됩니다.

## 기물 점수 테이블

| 기물 | 점수 |
|------|------|
| 폰 (Pawn) | 1점 |
| 퍼즈 (Ferz) | 1점 |
| 다바바 (Dabbaba) | 2점 |
| 알필 (Alfil) | 2점 |
| 나이트 (Knight) | 3점 |
| 비숍 (Bishop) | 3점 |
| 카멜 (Camel) | 3점 |
| 킹 (King) | 4점 |
| 그라스호퍼 (Grasshopper) | 4점 |
| 룩 (Rook) | 5점 |
| 센타우르 (Centaur, 킹+나이트) | 5점 |
| 아크비숍 (Archbishop, 비숍+나이트) | 6점 |
| 나이트라이더 (Knightrider) | 7점 |
| 퀸 (Queen) | 9점 |
| 아마존 (Amazon) | 13점 |

## 점수 용도
- **포켓 구성 제한**: 각 플레이어의 포켓(덱) 기물 점수 총합은 39점을 초과할 수 없습니다.
- **프로모션 시**: 프로모션할 기물을 선택할 때 참고됩니다.
